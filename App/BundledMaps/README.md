# BundledMaps

Dieser Ordner wird unverändert ins App-Bundle kopiert (Ordnerreferenz im Xcode-Projekt).
Die App bietet alle `*.map`-Dateien und alle Theme-XMLs in Unterordnern zur Auswahl an.
Inhalt außer dieser Datei ist nicht im Git (Größe, Lizenzen).

Prototyp-Stand:

- `bremen.map` – aus `TestData/` (MapsforgeKit-Referenzdaten)
- `Hamburg_oam.osm.map` – OpenAndroMaps V5, `mapsV5/germany/Hamburg.zip` von ftp.gwdg.de
- `elevate/` – Elevate 5.7 (Tobias Kühn, CC BY-NC-SA 4.0), `Elevate.zip` von openandromaps.org
